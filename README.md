# rm-podacast
This is a simple post type setup for those wanting to use the Rank Math Podcast Feature on a specific podcast post type.

Requires at least: 6.9.1
Tested up to: 6.9.4
Requires PHP: 8.3
Run NPM install to get started with compiler.

We have 2 compiler tools - composer and NPM.

npm for the scss around the styling of each widget.
